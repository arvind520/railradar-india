# 🚆 RailRadar India

A full-stack web application for discovering and tracking Indian trains near your location.

## 🚧 Project Status

Currently under development.

## 🎯 Goal

RailRadar India aims to provide users with:

- 📍 Location-based train discovery
- 🚆 Train running status
- 🗺️ Interactive railway map
- 🔎 Train search
- ⏱️ Delay information
- 📱 Responsive interface

## 🛠️ Planned Technology

- React
- Node.js
- Express.js
- MongoDB
- Leaflet
- OpenStreetMap
- Git & GitHub
